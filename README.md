# BUNZO® — Smash Burger · Nantes

Site vitrine statique (HTML/CSS/JS), mobile d'abord.

- Animations : GSAP + ScrollTrigger + SplitText, smooth scroll Lenis (fichiers dans `js/vendor/`)
- Polices hébergées dans `fonts/` (Archivo, Instrument Serif, Space Mono)
- `src/index.html` = source ; `python3 build.py` injecte le logo SVG (`assets/logo.svg`) et génère `index.html`
- Déploiement : Vercel, site statique (pas de build nécessaire, `index.html` est versionné)
